### 图像质量（IQ）评估

在计算机科学领域，图像质量评估通常采用像素级指标（如 PSNR）和感知指标（如 LPIPS）。这些指标是量化图像保真度的重要工具；不过，图像质量评价还涵盖更广泛的评估指标，其中既包括基于数值计算的客观度量，也包括融入人类判断以衡量视觉吸引力和感知质量的主观评价。
